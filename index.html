Gemini AI Studio Extraction Guide & Prompts

Use these copyable prompts in Google AI Studio on your phone or computer. Attach your vendor video file and Gemini reads both visuals and narration.

1. Whole-Video Extraction Prompt
You are analyzing a vendor's product video. It may be a WhatsApp chat screen recording, a person holding up or describing items one by one, or footage of a shelf or display. Use both the visuals and the audio. List every distinct product the vendor is offering, once each, even if it appears several times. For each product give: name, price (amount, currency, and source: on_screen, price_tag, spoken, or none), a short description (material, size, color, variants if mentioned), the timestamp in seconds of the clearest view of the item, and a confidence score from 0 to 1. For chat recordings, use only product-related message content and ignore timestamps, sender names and unrelated chatter. For shelf footage, list each visibly distinct item separately and use null for unknown price or quantity. Never invent a price: if none is shown or said, return null. Return only valid JSON matching the schema.
2. Structured Output JSON Schema
{ "type": "object", "properties": { "vendor_name": { "type": ["string", "null"] }, "vendor_phone": { "type": ["string", "null"] }, "currency_default": { "type": ["string", "null"] }, "products": { "type": "array", "items": { "type": "object", "properties": { "id": { "type": "string" }, "name": { "type": "string" }, "price": { "type": ["object", "null"], "properties": { "amount": { "type": ["number", "null"] }, "currency": { "type": ["string", "null"] }, "source": { "type": "string", "enum": ["on_screen", "price_tag", "spoken", "none"] } }, "required": ["amount", "currency", "source"] }, "description": { "type": "string" }, "category": { "type": ["string", "null"] }, "best_timestamp_sec": { "type": "number" }, "confidence": { "type": "number" } }, "required": ["id", "name", "price", "description", "best_timestamp_sec", "confidence"] } } }, "required": ["products"] }

☁️ Cloud Storage & Media CDN

Lightning-Fast Shared Storefronts: Connect your free Cloudinary or Supabase Storage account so product photos upload directly to a global CDN. This eliminates phone memory limits and keeps your catalog data lightweight!
Found on your Cloudinary dashboard overview.
In Cloudinary Console → Settings → Upload → Upload Presets: click Add Upload Preset and set Signing Mode to Unsigned.
⚡ Connected via Vercel Environment Variables
Supabase Storage is active via server-side environment variables (Bucket: catalog-images). Image uploads are handled securely by your Vercel serverless function with zero frontend credential exposure.
🔒 Recommended (Zero Frontend Input): Configure SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, and SUPABASE_BUCKET in your Vercel Project → Environment Variables. The fields below are optional client-side overrides.
Default is catalog-images (must be marked Public in Supabase Storage).
Uses the active server environment (Vercel Blob with BLOB_READ_WRITE_TOKEN, or the local development server). Zero client setup required.
